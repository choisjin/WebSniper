# WebSniper

브라우저에서 가볍게 즐기는 1인칭 저격 게임. 노을 아래 색색의 박스 건물(창문 텍스처)과 엄폐물, 나무로 이루어진 3D 도시에서 NPC(봇)와 싸우거나 같은 서버에 접속한 유저끼리 대전할 수 있습니다. 렌더링은 three.js(로컬 서빙), 물리·탄도·봇은 Node 서버가 담당합니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

환경 변수:

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `PORT` | 3000 | 서버 포트 |
| `BOTS` | 6 | 시작 시 NPC 수 (시작 화면에서도 변경 가능, 0~20) |
| `SEED` | 랜덤 | 맵 시드 (같은 시드 = 같은 맵) |

멀티플레이: 서버를 띄운 PC의 IP(예: `http://192.168.0.10:3000`)로 다른 사람이 접속하면 같은 맵에서 함께 플레이합니다. 외부에서 접속하려면 포트포워딩이나 터널(ngrok, cloudflared 등)을 사용하세요.

## 게임 규칙

- 맵은 600m × 600m이며 안의 건물은 전부 진입할 수 있습니다. 경계 벽 밖의 원경 건물은 장식입니다. 적은 1.8m 검은 스틱맨이라 색 있는 건물 앞에서는 눈에 띄지만 100m 밖에서는 점처럼 보입니다. 나무·덤불 뒤에 서면 시야에서 가려집니다(총알은 통과).
- 낮은 턱(0.6m 이하)은 걸어서 자동으로 올라가고, 1m 상자 등은 점프(Space)로 오릅니다.
- 건물은 속이 비어 있습니다. 출입구(폭 1.6m·높이 2.4m, 미니맵 노란 점)로 들어가면 한쪽 모서리에 계단실(미니맵 노란 사각)이 있고, 층마다 20cm 계단 18단 → 착지 → 18단으로 꺾어 올라가 옥상 해치로 나옵니다. 층고 7.2m, 1~6층. 계단·착지·층 구멍 둘레에 난간이 있습니다. 층마다 아이템이 생성되며 실내 바닥도 리스폰 지점입니다.
- 창문은 층마다 벽에 실제로 뚫린 개구부(폭 2.0m, 바닥에서 1.0~3.4m, 7.2m 간격이며 건물·층·벽마다 일부 자리는 비어 있음)입니다. 창을 통해 밖을 보고 사격할 수 있고 밖에서도 창 안의 적을 맞힐 수 있습니다. 서서 창턱(1m)에 기대면 몸이 드러나고, 앉으면 창 아래로 숨습니다.
- 건물 구조는 `shared/building.js`에서 서버와 클라이언트가 같은 코드로 생성합니다. 서버는 건물 파라미터만 보내므로 접속 시 맵 데이터가 작습니다.
- 낙하 피해: 착지 속도 12m/s(약 3.6m 낙하)까지는 무피해, 그 이상은 1m/s당 6 피해. 10m 낙하 약 48, 20m 낙하 약 96. 방어구로 줄지 않습니다. 봇은 절반만 받습니다.
- 아이템은 종류별 형태로 구분됩니다: 총(총 모양), 스코프(원통), 방탄복(조끼 판), 방탄모(돔), 소비템(파우치). 색도 종류별로 다릅니다.
- 탄도는 기본 캐주얼(낙차 2.5m/s²)로 300m에서도 0.15m 정도만 떨어져 조준점 그대로 맞습니다. 시작 화면의 "리얼 탄도"를 켜면 9.8m/s²로 300m에서 약 0.6m 떨어져 홀드오버가 필요합니다. 이 설정은 서버 전체(모든 플레이어)에 적용되며, 봇의 낙차 보정도 같이 바뀝니다.
- 헤드샷은 2.2배 피해. 방탄모/방탄복은 피해를 줄이고 내구도가 닳으면 파손됩니다.
- 총의 무게, 방어구, 가방 아이템 무게가 이동 속도와 조준 흔들림에 영향을 줍니다. 웅크리면 흔들림이 크게 줄어듭니다.
- 열감지 스코프는 배터리(초)를 소모하며, 배터리 아이템으로 충전합니다.
- 사망 시 모든 아이템을 떨어뜨리고 5초 후 기본 장비(VSS + 붕대)로 리스폰합니다.
- 맵에는 저격총, 스코프, 방탄복, 방탄모, 스테미너 드링크, 회복약, 배터리가 랜덤하게 계속 생성됩니다.

## 장비

저격총 (위력 / 연사 간격 / 탄수 / 무게 / 탄속)

| 총 | 위력 | 간격 | 탄수 | 무게 | 탄속 |
|----|------|------|------|------|------|
| VSS 빈토레즈 | 34 | 0.45s | 10 | 2.6 | 560 m/s |
| SVD 드라구노프 | 52 | 0.75s | 10 | 4.3 | 830 m/s |
| M24 (볼트) | 80 | 1.5s | 5 | 5.5 | 850 m/s |
| AWM (볼트) | 112 | 1.8s | 5 | 6.5 | 920 m/s |
| 바렛 M82 | 140 | 1.2s | 10 | 14 | 860 m/s |

반동은 총마다 다르며(VSS 1.7° ~ M82 5.2°) 시점이 위로 튄 뒤 70%가 0.35초에 걸쳐 되돌아옵니다. 앉으면 반동이 30% 줄어듭니다. 볼트액션은 사격 후 약 1초간 볼트를 조작하며 그동안 조준경이 해제됩니다.

스코프: 4x / 8x / 12x / 16x, 열감지 6x(60초) / 10x(45초). 스코프가 없으면 기본 조준경 3x.

수치는 `shared/defs.js`에서 조정할 수 있습니다.

## 구조

```
server/index.js   정적 파일 + WebSocket 서버 (60Hz 물리, 30Hz 전송)
server/game.js    3D 플레이어 물리(AABB, 자동 스텝업), 탄도, 피해, 인벤토리, 봇 AI
server/map.js     시드 기반 3D 맵 생성 (속 빈 건물 + 출입구 + 계단실, 난간, 엄폐물, 장식물, 원경)
shared/defs.js    아이템/플레이어 수치 (서버·클라이언트 공용)
shared/building.js 건물 구조 생성: 벽·출입구·층 슬래브·계단·난간·실내 창문 패널 (서버·클라이언트 공용)
public/client.js  three.js 1인칭 렌더링, 입력, 스코프/열감지, HUD(2D 캔버스 오버레이), 인벤토리 UI
/vendor/three.*   node_modules/three/build 에서 서빙 (외부 CDN 불필요)
```
